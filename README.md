## What Discord Shows

- **Application**: `Antigravity CLI`
- **Line 1 (Details)**: Customizable template, e.g.:
  - `Gemini 3.8 Flash (High Effort)`
- **Line 2 (State)**: Dynamic live agent action & metrics, e.g.:
  - `🧠 Thinking & Planning... (2 files edited) in Lil-D`
  - `📝 Editing hook_handler.py (🌿 main) (2 files edited)`
  - `⚡ Running npm test (🌿 main)`
  - `💤 Idle / Awaiting prompt (2 files edited)`
- **Git Branch**: Automatic 0.1ms branch detection (`🌿 main`, `🌿 dev`, etc.).
- **Code Diff Tracking**: Live code line changes counter (`+lines / -lines`, e.g. `(+45 -12 lines)`).
- **Files Modified Counter**: Live count of modified/created files in session.
- **Elapsed Timer**: Real-time timer showing session or prompt duration.
- **Tooltips & Badges**:
  - `Thinking: High | Step 125 | 18 tools`
  - Workspace / project name (or custom alias)
- **Buttons**: Clickable profile buttons (e.g. Antigravity CLI, GitHub, etc.)

## Quick Installation (One-Liner)

Open Windows **Command Prompt (CMD)** or **PowerShell** and run:

### Option A: Via Git (Recommended)
```cmd
git clone https://github.com/DasDastinPROs/antigravity-discord-rpc.git "%USERPROFILE%\.gemini\config\plugins\discord-rpc" && call "%USERPROFILE%\.gemini\config\plugins\discord-rpc\install.bat"
```

### Option B: Without Git (Native Windows 10/11 `curl` & `tar`)
```cmd
curl -sSL https://github.com/DasDastinPROs/antigravity-discord-rpc/archive/refs/heads/main.zip -o %TEMP%\rpc.zip && tar -xf %TEMP%\rpc.zip -C "%USERPROFILE%\.gemini\config\plugins" && ren "%USERPROFILE%\.gemini\config\plugins\antigravity-discord-rpc-main" discord-rpc && del %TEMP%\rpc.zip && call "%USERPROFILE%\.gemini\config\plugins\discord-rpc\install.bat"
```

### Available Template Placeholders

| Placeholder | Example Value | Description |
| :--- | :--- | :--- |
| `{model}` | `Gemini 3.8 Flash` | Active AI model name |
| `{effort}` | `High` / `Medium` / `Low` | Thinking effort level |
| `{status}` | `Thinking` / `Tool_use` / `Idle` | Current loop status |
| `{emoji}` | `🧠`, `📝`, `⚡`, `💤` | State emoji (configurable in `emojis`) |
| `{action}` | `Editing bot.py` | Human-readable action description |
| `{diff_info}` | `(+45 -12 lines)` | Formatted code line diff |
| `{diff_badge}`| `+45 -12` | Plain diff badge |
| `{lines_added}` | `45` | Total lines added |
| `{lines_removed}`| `12` | Total lines removed |
| `{tool}` | `replace_file_content` | Name of current tool executing |
| `{target}` | `bot.py` | File or command being acted on |
| `{workspace}` | `MyProject` | Current workspace folder name |
| `{branch}` | `main` | Git branch name |
| `{branch_info}` | `(🌿 main)` | Formatted git branch string |
| `{files_count}` | `3` | Count of unique files edited |
| `{files_info}` | `(3 files)` | Formatted files modified string |
| `{step}` | `42` | Current step index |
| `{tool_count}` | `14` | Total tool invocations in session |
